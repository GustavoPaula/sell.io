# Skills do projeto

Quando o usuário solicitar a criação de uma skill para este projeto, crie-a em `.agents/skills/<nome-da-skill>`.

# Testes

Toda descrição de teste implementado deve começar com "Deve".
Cada teste deve descrever e verificar um comportamento ou regra específica, com exemplos claros. Agrupe no mesmo teste apenas casos relacionados à mesma regra.

# Commits

Toda mensagem de commit deve seguir o padrão Conventional Commits: `<tipo>(<escopo opcional>): <descrição>`, por exemplo `feat(email): adicionar validação de domínio`.
